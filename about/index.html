🚀 项目经历

X_IOT 物联网平台

技术栈： .NET 10 + React 19 + TypeScript + Umi Max + PostgreSQL + MQTT

架构设计：

  • X.Cloud - 云端核心服务：API 网关、认证服务、IoT 核心、自动化引擎
  • X.Edge - 边缘计算服务：本地 MQTT Broker、网关管理、设备控制
  • 前端 - 云端后台 + 边缘端管理界面（React 19 + Ant Design Pro）

核心功能：

  • 多协议设备接入：支持 Zigbee、WiFi、BLE、KNX 等物联网协议
  • 自动化规则引擎：基于 Jint 执行 JavaScript 脚本，支持设备联动
  • AI 助手：集成 Ant Design X，支持 LLM 对话和工具调用
  • 多租户架构：TenantCatalog 配置驱动，支持多客户隔离
  • 云边协同：断网时边缘自治，联网后数据同步

Disney 酒店护照业务管理系统 (PassportDotnetAntd)

技术栈： .NET 10 + React 19 + Umi Max + Ant Design 6 + MySQL + FreeSql

项目概述：
为 Disney 酒店开发的护照业务管理系统，支持护照扫描录入、状态跟踪、批量管理。

技术实现：

  • 后端：.NET 10 + FreeSql ORM，支持多租户、全局异常处理、定时任务调度
  • 前端：React 19 + Umi Max + Ant Design 6，现代化 SPA 应用
  • 认证：MyID OAuth2 Authorization Code + JWT Token
  • 部署：Docker Compose + Linux 一键部署脚本
