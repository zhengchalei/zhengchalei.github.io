Q2: 图标显示为方块 □

原因： 字体不支持

解决：

  1. 安装 Nerd Font：oh-my-posh font install JetBrainsMono
  2. Windows Terminal 设置 → 外观 → 字体 → 选择 JetBrainsMono NF
  3. 重启终端
